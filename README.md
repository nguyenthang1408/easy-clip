# tool_truyen_audio

Có 3 project : ReviewMovie ,SlideToVideo ,ToolNews 
Các tính năng:
 + ReviewMovie : tool chính để sử dụng là tin tức (news) , review ảnh & phim , lời khớp với media
 + SlideToVideo : Sử dụng làm tool truyện , sile dạng ảnh , lời sẽ không khớp với media
 + ToolNews : Tool cũ , làm slide theo thư mục , hiển thị sóng âm thanh dùng cho làm nhạc (tham khảo)

Chi tiết chức năng : 
* ReviewMovie (Phiên bản V1.0.0): 
 - Tạo project , nhưng chỉ chạy được đơn lẻ 
 - Option chứa nhiều hạng mục , chưa gom được vào với nhau
 - Nhập text để tạo video vẫn bị lỗi
 - Phần set time cho media chưa rõ ràng
 - Ảnh được thay đổi về size chuẩn với nhiều loại kích thước -> cần update trong version tới
 - Hiệu ứng zoom ảnh cũ
